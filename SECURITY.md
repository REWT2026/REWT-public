# Security

## Reporting a vulnerability

Please report suspected security vulnerabilities through this repository's
GitHub Private Vulnerability Reporting facility. Do not publicly disclose an
unpatched vulnerability before it has been reviewed.

Do not include real credentials, tokens, API keys, or other secrets in a
report. Do not perform destructive testing, test against private REWT
infrastructure, or attempt to access systems or data outside the published
facade.

## Public-facade boundary

This repository is designed for offline technical inspection. Its demonstration
uses a deterministic provider and requires no provider credential. It is not
the complete private REWT system.

No response-time commitment or security-service level is promised by this
repository.
